# Luis Filipe Crivellaro — Portfolio

Personal portfolio of Luis Filipe Crivellaro, Software Engineer focused on AI & Automation.

## Stack

- [Next.js](https://nextjs.org) (App Router) + TypeScript
- Tailwind CSS
- GSAP + ScrollTrigger
- Framer Motion
- Lucide React

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Structure

```
src/
  app/            App Router entry, layout, metadata, generated icons
  components/
    layout/       Navbar, mobile menu, footer
    sections/     Page sections (Hero, About, Experience, Projects, Skills, GitHub, Contact)
    ui/           Reusable primitives (reveal animations, cursor, cards, marquee, visuals)
  lib/            Content data, utilities, hooks
```

## Build

```bash
npm run build
```
